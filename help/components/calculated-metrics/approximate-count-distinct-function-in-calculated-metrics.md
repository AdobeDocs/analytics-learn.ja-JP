# 計算指標の近似個数分布関数 {#approximate-count-distinct-function-in-calculated-metrics}

選択したディメンションのディメンション項目の概算ユニーク数を返す「概算カウント別除関数」を使用して、計算指標を作成する方法を説明します。

>[!VIDEO](https://video.tv.adobe.com/v/23722/?quality=12&learn=on)

このビデオに示す指標を任意のレポートで使用して、あるディメンションの数を他のディメンションの値と比較して把握できます。 非常に一般的な使用例としては、この関数を使用して顧客ID指標を作成し、任意のレポートで使用して、異なるディメンション値に適用される顧客数を確認できます。
