# データフィードジョブの再実行

Adobe Analyticsのデータフィード UIを使用すると、データフィードの管理がはるかに簡単になります。 データフィードを管理するアクセス権がある場合は、カスタマーサポート部門にデータフィードファイルを再送信させることなく、データフィード UIでデータフィードジョブを自分で再実行できます。
