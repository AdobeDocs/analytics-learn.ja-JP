# Adobe Analytics での [!UICONTROL サーバーコールの使用状況] {#server-call-usage-in-adobe-analytics}

[!UICONTROL &#x200B; サーバーコールの使用状況] レポートを使用すると、任意の時点で使用したサーバーコールのコミットメントの正確な量を追跡することが可能になり、合計コミットメントに近づいているときにも積極的に警告されます。

>[!VIDEO](https://video.tv.adobe.com/v/23137/?quality=12&learn=on)

組織のサーバーコールの消費量を正確に把握するのは難しい場合があり、超過に対するフラストレーションにつながります。 [!UICONTROL &#x200B; サーバーコールの使用状況] レポートを使用すると、任意の時点で使用したサーバーコールコミットメントの正確な量を追跡でき、合計コミットメントに近づいているときにも積極的に警告します。 付属のダッシュボードを使用すると、サーバーコールが使用されている場所を分析できるので、逸脱した実装を修正したり、同僚と協力して、価値の低い大量のデータを収集している可能性のある場所の規模を縮小することができます。
