# Analysis Workspace での静的行の並べ替え

フリーフォームテーブルビルダー内で、静的行を手動で並べ替えることができます。 これにより、訪問回数、購入回数、コンバージョン率など、テーブルの静的行を必要な順序に並べることができます。
