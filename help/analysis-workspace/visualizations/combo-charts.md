# Analysis Workspace の複合グラフ

Analysis Workspace での複合グラフビジュアライゼーションについて説明します。 コンボチャートのビジュアライゼーションにより、最初にテーブルを作成することなく、比較ビジュアライゼーションをすばやく簡単に作成できます。 折れ線グラフと棒グラフの組み合わせでデータの傾向を簡単に表示できます。
