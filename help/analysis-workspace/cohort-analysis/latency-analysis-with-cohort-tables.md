# [!UICONTROL コホートテーブル] を使用した待ち時間分析 {#latency-analysis-with-cohort-tables}

[!UICONTROL コホートテーブル] の [!UICONTROL 待ち時間テーブル] 設定を使用すると、（標準 [!UICONTROL コホート] が示すように）インクルージョンイベントの前後の [!UICONTROL コホート] の動作を分析できます。 この設定は、例えば、新しい製品やキャンペーンのローンチが与える影響を分析する場合に役立ちます。
